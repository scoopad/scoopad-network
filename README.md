# 🥄 Scoopad

> **Launch fair tokens that can be mined through grid games, staking & burning.**

Scoopad is a fully on-chain token launch platform built around **fair distribution, community participation, and transparent token mechanics**.

No presale.
No team allocation.
No hidden distribution.

Just on-chain participation.

🌐 Website: http://scoopad.org/
𝕏 X: https://x.com/scoopadOrg

---

## 🚀 What is Scoopad?

Scoopad introduces a different approach to token launches.

Instead of relying on private allocations or presales, tokens are designed to be distributed through on-chain mechanisms such as:

* 🎮 Grid Games
* 🔒 Staking
* 🔥 Burning
* ⛏️ Mining
* 🌐 Community Participation

Every mechanism is designed to be transparent and verifiable on-chain.

---

## ⚖️ Fair Launch

Scoopad is built around a simple principle:

> **Everyone plays by the same rules.**

### No Presale

There is no private presale giving selected participants early access.

### No Team Allocation

No token supply is reserved for a team allocation.

### Fully On-Chain

Token mechanics are designed to operate through smart contracts rather than centralized distribution.

### Community Driven

Participants earn through interaction with the protocol and its mechanisms.

---

## 🎮 Grid Mining

Grid games are one of the core ways users can participate in Scoopad.

Players interact with an on-chain grid where participation can contribute toward token mining and rewards.

```text
        GRID GAME
            │
            ▼
      ┌───────────┐
      │  PLAYERS  │
      └─────┬─────┘
            │
            ▼
       GRID ACTION
            │
            ▼
        ON-CHAIN
            │
            ▼
       TOKEN MINING
```

The grid transforms token distribution into an interactive experience.

## ⛏️ Mining

Scoopad tokens can be earned through protocol participation.

Mining is designed to reward users who actively participate rather than simply relying on an early allocation.

Possible mining activities include:

* Grid participation
* Staking
* Protocol interactions
* Community campaigns
* Other on-chain activities

## 🔒 Staking

Users can stake eligible assets to participate in the Scoopad reward system.

```text
   │  STAKING  │
   └─────┬─────┘

```

Staking mechanics are governed by smart contracts and can be independently verified on-chain.

---

## 🔥 Burning

Burning is another core mechanism within Scoopad.

Tokens sent to a burn address are permanently removed from circulation.

```text
TOKEN SUPPLY
      │
      ▼
   BURNING
      │
      ▼
SUPPLY REDUCTION
```

Burning can be incorporated into token mechanics, game interactions, or protocol activities.
